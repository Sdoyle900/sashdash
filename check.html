🔙 Roll back

If an update goes wrong: pick the older index.html you want back (e.g. from GitHub → Releases → stable-… → Source code). This gives it a new, higher build number, so every phone moves back to it, and saves it as index.html for you to upload.

📄 Pick the older index.html
  1. The file index.html is in your Downloads.
  2. Drop it on the Release check above if you like (it should pass).
  3. GitHub → Add file → Upload files → drag in index.html → Commit changes.
  4. Phones and computers move back to it within about 15 minutes.
